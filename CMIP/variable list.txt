====================================================================================================
                             VARIABLES CMIP6 : LISTE COMPLÈTE PAR TABLE                             
====================================================================================================

Ce fichier liste les 2062 variables des 43 tables de la demande de données CMIP6 (version 01.00.33,
tables du 18 November 2020). Il est généré à partir des fichiers officiels du dépôt PCMDI :
https://github.com/PCMDI/cmip6-cmor-tables

Une variable s'identifie par le couple table + code, par exemple Amon/tas ou day/pr. Dans le
catalogue Google Cloud, la table correspond à la colonne table_id et le code à la colonne
variable_id. Une variable listée ici n'est pas forcément fournie par tous les modèles ni pour tous
les scénarios : il faut vérifier dans le catalogue.

Les noms complets sont les noms officiels, en anglais.

----------------------------------------------------------------------------------------------------
LÉGENDE DES COLONNES
----------------------------------------------------------------------------------------------------

  Code         nom de la variable (variable_id dans le catalogue)
  Unité        unité officielle. 1 = sans dimension ; kg m-2 s-1 pour un flux d'eau (multiplier par
               86400 pour des mm/jour) ; K pour une température (retirer 273.15 pour des °C)
  Fréq.        mon = mensuel, day = journalier, 3hr / 6hr / 1hr = toutes les 3, 6 ou 1 heures, yr =
               annuel, dec = décennal, subhr = pas de temps du modèle, fx = fixe, monC =
               climatologie mensuelle, 1hrCM = cycle diurne mensuel. Le suffixe Pt indique une
               valeur instantanée plutôt qu'une moyenne
  Statistique  moyenne, instantané, maximum, minimum, cumul, climatologie (moyenne sur plusieurs
               années), cycle diurne, moy. des max / moy. des min (moyenne des extrêmes
               journaliers), moy. condit. (moyenne sur une partie seulement : un secteur, les zones
               nuageuses...)
  Couverture   grille = carte complète ; zonale = moyenne par latitude ; mondiale = une seule valeur
               pour la planète ; sites = liste de points ; par bassin = par bassin océanique ;
               Antarctique / Groenland = grilles des calottes
  Niveaux      dimension verticale ou autre dimension en plus de la position et du temps. « - » = un
               seul niveau (surface ou colonne entière)

  Niveaux de pression les plus courants :
    8 niv. pression  (plev8)  : 1000, 850, 700, 500, 250, 100, 50, 10 hPa
    19 niv. pression (plev19) : 1000, 925, 850, 700, 600, 500, 400, 300, 250, 200, 150,
                                100, 70, 50, 30, 20, 10, 5, 1 hPa
    27 et 39 niveaux : grilles plus fines, utilisées dans quelques tables étendues
    niv. modèle : niveaux propres à chaque modèle, à convertir avec ps et les coefficients du modèle
